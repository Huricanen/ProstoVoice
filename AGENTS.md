# ProstoVoice — инструкции для агентов

## Состояние

Репозиторий содержит offline Android-приложение для транскрибации и diarization на Whisper.cpp/sherpa-onnx. Native debug-сборка поддерживает `arm64-v8a` и `x86_64` (Android Studio эмуляторы).

## Правила работы

- Не добавлять тяжёлые модели в Git; исходники небольших native-зависимостей допускаются, если они нужны для воспроизводимой сборки.
- Не отправлять аудио, модели или результаты на внешний сервер.
- Сохранять offline-сценарий, Android UI, JNI/native-границы и возможность Whisper-only fallback.
- Не создавать коммиты и не отправлять изменения в remote без отдельного запроса.
- Проверять фактические версии Android SDK, Gradle, NDK и доступные ABI перед настройкой сборки.
- Не считать unit-тесты заменой проверки на эмуляторе или физическом устройстве.

## Проверки

Используй JDK 17+ и wrapper:

- `./gradlew assembleDebug` (PowerShell: `./gradlew.bat assembleDebug`)
- `./gradlew test`

Native build дополнительно требует установленный Android NDK `27.2.12479018` и CMake `3.22.1`. Проверяй обе ABI, если меняется native-код или `abiFilters`. Не выдавай успешную сборку native за подтверждённую без этих инструментов.
