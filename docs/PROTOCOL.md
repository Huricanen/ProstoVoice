# ProstoVoice: установка и использование

## Установка

1. Установите APK `app-debug.apk` на Android-устройство с ABI `arm64-v8a`.
2. Запустите ProstoVoice.
3. Разрешите уведомления, если приложение запросит разрешение: оно используется для фоновой обработки.

Для сборки из исходников нужны JDK 17+, Android SDK, NDK `27.2.12479018` и CMake `3.22.1`:

```powershell
./gradlew.bat assembleDebug
```

APK будет создан в `app/build/outputs/apk/debug/app-debug.apk`.

## Обработка записи

1. Нажмите «Выбрать аудиофайл» и выберите локальную аудиозапись через системный picker.
2. Выберите режим:
   - «Автоматически определить голоса» — число speakers оценивается по embeddings;
   - «Обработать как один голос» — diarization отключается, весь текст получает `speaker_1`.
3. Дождитесь завершения фоновой обработки. Прогресс и итоговое время показываются в приложении и уведомлении.
4. Используйте закреплённый снизу плеер: воспроизведение, пауза, стоп и перемотка. Цветные блоки на шкале показывают интервалы реплик.
5. Нажмите `TXT` или `JSON` для экспорта результата.

## Библиотека

Завершённые обработки сохраняются локально в библиотеке. Нажатие на запись открывает transcript и исходное аудио в плеере. Кнопка «Удалить» убирает результат из библиотеки, но не удаляет исходный файл с устройства.
