# DECISIONS

## Принятые решения

### 2026-11-06 — сохранить репозиторий лёгким до получения ТЗ

- **Контекст:** исходники и точные требования ещё отсутствуют.
- **Решение:** не добавлять в Git Android-каркас, native-библиотеки или модели до уточнения ТЗ; подготовить только документацию и безопасный `.gitignore`.
- **Основание:** требуется избежать ранней фиксации несовместимых решений и разрастания репозитория.
- **Последствия:** реализация и точные команды сборки пока невозможны.

## Ожидают подтверждения

Минимальный Android API, ABI, UI toolkit, формат поставки моделей, допустимый размер APK, фоновые задачи, лицензии моделей и обязательность diarization должны быть подтверждены ТЗ.
