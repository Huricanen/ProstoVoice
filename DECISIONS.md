# DECISIONS

## Принятые решения

### 2026-11-06 — начать с минимального Android-каркаса

- **Контекст:** команда дала команду начать реализацию до получения полного ТЗ.
- **Решение:** создать обратимый Kotlin DSL/Compose-каркас с SAF и контрактом `TranscriptionOrchestrator`, не добавляя модели и native runtime.
- **Основание:** позволяет подготовить UI и границы pipeline без фиксации неизвестных требований.
- **Последствия:** реальная обработка и сборка остаются неподтверждёнными до установки JDK/Gradle/NDK/CMake и подключения моделей.

### 2026-11-06 — изолировать native runtime и сохранить fallback

- **Контекст:** native toolchain и модели пока недоступны.
- **Решение:** JNI boundary и C++ stub не подключаются к Gradle до подтверждения NDK/CMake; UI сохраняет возможность Kotlin/Whisper-only fallback.
- **Основание:** не блокировать проверку UI и контрактов отсутствующими инструментами.
- **Последствия:** native status сейчас stub и не выполняет распознавание.

### 2026-11-06 — сохранить репозиторий лёгким до получения ТЗ

- **Контекст:** исходники и точные требования ещё отсутствуют.
- **Решение:** не добавлять в Git Android-каркас, native-библиотеки или модели до уточнения ТЗ; подготовить только документацию и безопасный `.gitignore`.
- **Основание:** требуется избежать ранней фиксации несовместимых решений и разрастания репозитория.
- **Последствия:** реализация и точные команды сборки пока невозможны.

## Ожидают подтверждения

Минимальный Android API, ABI, UI toolkit, формат поставки моделей, допустимый размер APK, фоновые задачи, лицензии моделей и обязательность diarization должны быть подтверждены ТЗ.
